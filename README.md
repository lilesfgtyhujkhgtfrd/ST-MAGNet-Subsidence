# 广域城市地下水超采区时空沉降趋势预测与驱动机制分析


本仓库为大创项目的全部可复现代码、数据中间产物与成果图件。核心工作是：以 PS-InSAR
时序形变场为基础，构建"水文地质单元 + 空间邻近/环境相似图结构"，用三分支图-注意力网络
（ST-MAGNet）预测未来 6/12 个月沉降，并通过门控权重、注意力、邻居贡献度与驱动因子置换
重要性解释沉降的驱动机制。

## 3. 数据来源与预处理

| 数据 | 来源 | 处理要点 |

## 4. 方法

1. **垂直向换算**：LOS 位移按固定入射角 38.5° 换算为垂直向（cos 38.5° ≈ 0.787），
   仅作趋势解释用，不改变时序形态。
2. **水文地质单元**：UTM 50N 下 600 m 规则网格，单元内 ≥30 个 PS 点取中位数序列；
   得 928 个含点单元，其中 865 个满足阈值，覆盖约 311 km²。MAD×6 剔除跳变（修正 80 个观测，占 0.25%）。
3. **地理亚区**：对单元质心做 KMeans(k=4)，按质心纬度命名北/中北/中南/南亚区（275/142/210/238 个单元）。
4. **图结构**：KNN(k=8) 空间邻近边 + 环境因子余弦相似度补充边（候选 25 近邻中取相似度最高 4 个、阈值 0.6），
   边权 `w = exp(-d/d0) × (0.6 + 0.4 × sim)`（d0 取邻距中位数 588 m），对称化后行归一化。
   结果：865 节点、4,802 边、平均度 11、中位邻距 392 m。
5. **ST-MAGNet**：三分支并行编码 + 门控融合
   - 空间分支：2 层 GraphSAGE（均值聚合，d=64），输入 13 维静态环境/相干性特征；
   - 时序分支：多周期位置编码（12/6/3 月正弦 + 线性趋势）+ 2 层 4 头 TransformerEncoder（d=64）；
   - 诱发分支：2 层 GRU（5 维驱动：降水、气温、地下水位异常、深层开采量、土壤湿度，d=32）；
   - 融合：`g = σ(W z + b)`，`z ← LayerNorm(g ⊙ z + z)`，输出未来 12 个月逐月增量位移（mm）。
6. **训练**：AdamW(lr=1e-3, wd=1e-4)、余弦退火、梯度裁剪 5.0；损失为逐月 MSE 的加权和
   （第 6、12 月权重 2.0/2.5）；全窗口批量训练（空间分支每步只算一次再广播），
   验证集早停（patience=18，上限 110 epoch）。
7. **评估协议**：`spatial`（按单元 70/15/15 划分，评估未见单元泛化）与 `temporal`
   （训练窗口末端 11—19、验证 20—22、测试 23—25，评估时间外推）；指标为 RMSE、MAE、R²、
   Pearson r 及趋势符号一致率。
8. **基线**：持续法（预测增量为 0）、线性趋势外推（最近 12 个月月均增量外推）、MLP、LSTM、
   Transformer、GCN+LSTM、GAT+LSTM，以及 ST-MAGNet 去诱发/去空间/去时序三组消融。
9. **可解释性**：门控分支权重占比、Transformer 最后时刻注意力、邻居遮挡贡献（空间传播方向）、
   驱动通道时间置换重要性、静态因子置换重要性、地下水位—沉降交叉相关滞后。

## 5. 结果

### 5.1 预测精度（RMSE / mm）

| 模型 | 空间协议 h6 / h12 | 时间协议 h6 / h12 |
|---|---|---|
| 持续法 | 14.92 / 29.68 | 14.36 / 28.36 |
| 趋势外推 | 2.23 / 2.95 | 2.35 / 2.75 |
| MLP | 2.63 / 3.91 | 2.47 / 3.54 |
| LSTM | 3.42 / 6.49 | 3.39 / 6.32 |
| Transformer | 1.99 / 2.59 | 2.00 / 2.39 |
| GCN+LSTM | 2.79 / 4.21 | 2.71 / 4.45 |
| GAT+LSTM | 2.87 / 4.37 | 2.87 / 4.11 |
| **ST-MAGNet** | **2.01 / 2.68** | **2.02 / 2.48** |
| ST-MAGNet 去诱发 | 2.06 / 2.72 | 2.02 / 2.27 |
| ST-MAGNet 去空间 | 1.97 / 2.49 | 1.95 / 2.63 |
| ST-MAGNet 去时序 | 9.16 / 17.19 | 6.44 / 12.73 |

ST-MAGNet 的 h12 R² 为 0.986（空间）/ 0.987（时间），显著优于持续法与 LSTM、GCN/GAT+LSTM；
与纯 Transformer 的差距仅 0.02—0.09 mm，小于空间协议 h12 的种子波动（0.20 mm），
**不能宣称优于 Transformer**。线性趋势外推是必须超越的强基线（h12 R²=0.983）：
默认种子下本模型误差低约 10%，但三种子平均后优势收缩至 3%—5%。

多种子稳健性（`outputs/tables/stmagn_stability.csv`，seed=0/1/2）：
空间协议 h6 2.01/2.12/2.19（2.11 ± 0.08）、h12 2.68/2.79/3.14（2.87 ± 0.20）；
时间协议 h6 2.02/2.10/2.04（2.05 ± 0.03）、h12 2.48/2.56/2.50（2.51 ± 0.03）。

### 5.2 消融结论（负结果）

时序分支是精度的绝对来源：去掉后 h12 RMSE 由 2.68 升至 17.19 mm（空间）、R² 由 0.986 降至 0.409。
去掉空间分支或诱发分支对精度影响很小（±0.2 mm，个别协议下略优）。在 36 个月样本长度上，
静态图结构与月度诱发代理**未带来显著精度增益**，其价值主要体现在可解释性（邻域贡献、
空间传播方向、驱动归因）与外推稳定性上。该结论与"GCN/GAT+LSTM 劣于纯 Transformer"相互印证。

### 5.3 可解释性

- 门控分支平均占比：空间 0.252 / 时序 0.415 / 诱发 0.332；
- 注意力峰值：865 个单元中 796 个（92.0%）集中于 2019-11，即采暖季起始月；
- 诱发通道置换重要性：气温 0.708、地下水位 0.097、开采量 0.096、降水 0.019、土壤湿度 0.004
  （气温与采暖季相位共线，应理解为"季节相位整体贡献"）；
- 静态因子置换重要性前四：铁路距离 0.244、水系距离 0.180、建筑密度 0.178、市中心距离 0.141；
- 地下水位—沉降滞后中位 11 个月，但相关系数中位仅 0.096，线性耦合弱。

### 5.4 未来 12 个月预测（2020-04—2021-03）

区域平均增量 6 个月 −8.5 mm、12 个月 −17.3 mm；亚区 12 个月：北 −27.1、中北 −16.5、
中南 −16.9、南 −6.6 mm；单单元极值 −61.4 mm（北亚区 #725、#816）。历史速率 2017—2020 年
基本稳定（−15.8 / −16.6 / −16.2 / −16.4 mm/a），未观测到与市级压采统计同步的显著减缓。

## 6. 局限

- 时序长度 38 期（36 个月），仅能支撑 12 个月回看/12 个月预测的监督样本，时间外推测试窗口仅 3 个；
- 地下水位与开采量为重建代理，非逐月实测，驱动机制结论需以"代理—相关"而非因果表述；
- 垂直向换算采用固定入射角，未做分层水准/承压含水层组校正；
- 研究区为城市建成区（建成区单元占 90.5%），结论不宜直接外推到全平原。
